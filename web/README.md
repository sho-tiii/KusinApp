# KusinApp — Web Application (`/web`)

This directory houses the React 18 + Vite web companion and administrative portals for KusinApp.

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Copy environment configuration
cp .env.example .env
# Fill in your Firebase API key in .env

# 3. Start local development server
npm run dev
```

For the complete project setup guide, feature testing walkthrough, and sprint backlog roadmap, please consult the root [README.md](../README.md).
